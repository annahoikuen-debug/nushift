### ステップ 1: `src/shiftai/ui/steps.py` を新規作成する

**目標**: ステップ番号・見出し・タブ参照文言の唯一の情報源を作る。
以降このファイル以外へ番号リテラルを書かない。

**新規作成ファイル**: `src/shiftai/ui/steps.py`

**操作**:

1. ファイルを作成し、**モジュール docstring** を書く。内容には次の 3 点を含める。
   - 案1 として番号・見出し・導線文言の単一情報源として新設したこと
   - `streamlit_app.py` から `sidebar.py` までのすべての表示がここを参照すること
   - 番号リテラルを他のファイルへ書かないこと
2. `from __future__ import annotations` を 1 行目に書く。
3. `from dataclasses import dataclass` を import する。
4. 次の dataclass を定義する。**フィールドごとにコメントを付ける。**

```python
@dataclass(frozen=True)
class Step:
    """1 つのステップ（タブ）の表示情報。"""

    index: int
    """上級者モード（5 タブ）での 0 始まり番号。"""

    key: str
    """モードに関係なく同じステップを指す機械可読な識別子。"""

    label: str
    """進捗チップに出す短い名前。先頭に丸数字を含む。"""

    title: str
    """タブの H3 見出しの文字列。先頭に算用数字と中黒を含む。"""

    tab_ref: str
    """他の画面からこのステップを参照するときの呼び方（例: タブ3）。"""
```

5. `EXPERT_STEPS` を定義する。**要素の並びと値をこの表から 1 文字も変えない。**

| index | key | label | title | tab_ref |
| --- | --- | --- | --- | --- |
| 0 | data | ① データ投入 | 1. データ投入 | タブ1 |
| 1 | requirements | ② 必要人員 | 2. 必要人員 | タブ2 |
| 2 | solve | ③ シフト作成 | 3. シフト自動作成 | タブ3 |
| 3 | shift | ④ シフト表・微調整 | 4. シフト表・微調整 | タブ4 |
| 4 | export | ⑤ 出力 | 5. 出力 | タブ5 |

6. `SIMPLE_STEPS` を定義する。**要素は 3 つ**で、`key` と `title` は上表の
   `data` / `solve` / `export` と一致させる。`label` と `tab_ref` は下表にする。

| 並び | key | label | title | tab_ref |
| --- | --- | --- | --- | --- |
| 0 番目 | data | ① データ | 1. データ投入 | タブ1 |
| 1 番目 | solve | ② シフト作成 | 3. シフト自動作成 | タブ2 |
| 2 番目 | export | ③ 出力 | 5. 出力 | タブ3 |

7. `SIMPLE_INDEX` を定義する。**キーが 0 から 4 の 5 つすべてを含める**
   （既存試験が `set(STEP_INDEX_SIMPLE) == set(range(5))` を検査する）。

```python
SIMPLE_INDEX: dict[int, int] = {0: 0, 1: 1, 2: 1, 3: 1, 4: 2}
```

8. 次の 2 関数を定義する。**どちらも docstring を書く。**

```python
def steps_for_mode(simple: bool) -> tuple[Step, ...]:
    """simple が真なら SIMPLE_STEPS、偽なら EXPERT_STEPS を返す。"""


def step_by_key(key: str) -> Step:
    """key から上級者モード基準の Step を返す。見つからない場合は ValueError。"""
```

`test_死んだ公開関数がない` だけであることを確認する（0.5 のとおり）。

    対象は園設定（開所閉所時刻・粒度・休業日・祝日・人件費）、

def mark_inputs_changed(reason: str) -> None:
    """入力が変わったときに呼ぶ。計算結果を破棄し理由を記録する。

### ステップ 23: シフト表側が修正対象を受け取る

**目標**: ステップ 22 で押されたボタンが、実際に該当セルへ誘導する。

**変更ファイル**: `src/shiftai/ui/tab_shift.py`

**操作**:

1. `render_section()` の**先頭**、既存の `day = _current_day()` の**直前**に、
   次のブロックを 1 塊として追加する。**そのまま貼り付けてよい。**

```python
target = state.take_fix_target()
if target is not None:
    iso_day, staff_id, slot_label = target
    wanted = date.fromisoformat(iso_day)
    options = components.day_options(state.get(state.KEY_SOLVE_RESULT))
    if wanted in options:
        st.session_state["active_day"] = wanted
        st.session_state["_fix_slot_label"] = slot_label
        st.info(
            f"修正対象: {theme.format_day(wanted)} ／ {staff_id} ／ {slot_label}"
            " のセル。下の「✏️ 微調整」で変更できます。"
        )
    else:
        st.session_state.pop("_fix_slot_label", None)
        st.warning("修正対象の日付が現在のシフトに存在しません。期間を確認してください。")
    st.session_state[state.KEY_FIX_REQUESTED] = False
```

2. 上のコードで守るべき点は次の 3 つ。
   a. `take_fix_target()` は 1 回だけ呼ぶ。**2 回以上呼ぶと 2 回目は必ず `None` になる。**
   b. `active_day` には **`date` オブジェクト**を入れる。
      `components.day_options` が返すのは `date` であり、`selectbox` の選択肢と
      同じ型でなければならない。ISO 文字列を入れると選択肢と一致せず反映されない。
      そのため `date.fromisoformat(iso_day)` で変換してから比較し、入れる。
   c. `_fix_slot_label` は `st.session_state` に**残す**。
      `take_fix_target()` は 1 回で消えるため、時間帯ラベルだけ別のキーに残す。
      対象の日付が無いときは `pop` して古い値を残さない。
3. `tab_shift.py` は既に `from datetime import date` と
   `from shiftai.ui import components, gantt, state, theme` を import 済みである。
   **追加 import は不要。**

   導線を 1 つ追加する。次の 3 行をそのまま追加する。

```python
slot_label = st.session_state.get("_fix_slot_label")
if slot_label:
    st.markdown(f"修正セル: **{slot_label}**")
```

   **`_fix_slot_label` は手順 1 のコードが設定する。**
