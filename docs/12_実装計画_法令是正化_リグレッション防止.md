- 実装は docs/11 §8 に従う。
- 主な変更点：
  - `src/shiftai/gap_analysis.py`
    - 行502-516 の `STATUTORY_DAILY_HOURS` ベースの判定を削除。
    - 新たに `OVERTIME_NOT_ALLOWED`（BLOCKER、`overtime_allowed=False` かつ 実働 > 8h）および `OVERTIME_REQUIRES_36AGREEMENT`（WARNING、`overtime_allowed=True` かつ 実働 > 8h）を追加。
    - 法定労働時間は「実働8時間」（第32条第2項）とし、休憩（第34条）は別要件であることをコメントに明記。
  - `src/shiftai/solver.py`
    - 行104-109 の `_daily_cap_minutes` を次のように改訂（法定8時間上限と園ルール10時間の頭打ちを実装）：
      ```python
      def daily_cap_minutes(contract: Contract) -> int:
          base = int(round(contract.daily_hours * 60))
          statutory = config.STATUTORY_DAILY_WORK_HOURS * 60   # 8h
          facility = int(config.FACILITY_MAX_DAILY_WORK_HOURS * 60)   # 園ルール
          if not contract.overtime_allowed:
              return min(base, statutory, facility)
          return min(int(base * config.STATUTORY_OVERTIME_MULTIPLIER), facility)
      ```
    - また `live_validation.py` も同様に置換。
  - 違反コードラベル・メッセージは `gap_analysis.py` の `VIOLATION_CODE_LABELS` に追加し、`docs/02` 等の一覧も更新。
