# 12. 実装計画 — 法的論拠の厳格化とリグレッション防止

本計画は、プロジェクト全体の法制面（労働基準法・労働安全衛生法・児童福祉法および関連告示）の引用誤りを総点検し、法令の条文番号や根拠を厳密に修正したうえで、回帰防止のための静的ガードテストおよび動的テストを体系的に導入する詳細計画である。

---

## 0. 法的前提の総点検（本計画の核心）

これまでの自己レビュー（`docs/11` 等）およびコードベースに含まれていた主な法的誤認と、その正しい法的位置づけを固定する。

### 0.1 条文番号・根拠法令の修正一覧

| 誤った前提・記述 | 正しい法令上の根拠 | 修正方針 |
| --- | --- | --- |
| **労働基準法第9条**（労働時間・休息） | 第9条は**定義（労働者）**。<br>労働時間は**第32条**（第1項：1週40時間、第2項：1日8時間）。<br>休憩は**第34条**（6h超45分、8h超60分）。 | `local_rules.py`、`domain.py`、`gap_analysis.py` 等のコメント・ドキュメントの「第9条（労働時間・休息）」をすべて「第32条（労働時間）」「第34条（休憩）」に訂正する。 |
| **勤務間休息11時間**の根拠を労基法第9条とする | 労基法には11時間休息の条文はない。<br>根拠は**労働安全衛生法第68条第2項**（継続11時間以上の休息を確保するよう努める等）。 | `domain.py`、`gap_analysis.py`、`docs/02` 等の「労働基準法第9条（休息時間）」を「労働安全衛生法第68条第2項（勤務間休息）」に訂正する。 |
| **第32条の3**を「休息日」とする | 第32条の3は「始業・終業時刻の決定を委ねる労働者（フレックス・清算期間型）」。<br>休日は**第35条**、年休は**第39条**。 | `local_rules.py` の「第32条の3（休息日）」を訂正する。 |
| **docs/11 §0.2**「1日10時間の上限という条文は存在しない」 | **労働基準法第32条の5**が存在する（繁閑の著しい業務、常時使用する労働者数が一定数未満、労使協定等の要件下で1日10時間まで可）。 | docs/11 の当該記述を訂正し、本ツールでは同条の要件（協定・届出・規模要件）の有無を判定できないため「**園ルール（実働10時間上限）**」として扱う旨を明確化する。 |
| **STATUTORY_WEEKLY_WORK_HOURS = 44** を法定とする | 44時間は2019-04-01に失効した旧基準。現行は週40時間（第32条第1項）。 | `config.py` のコメントを「社内目安（旧基準・厳しい方）」に改め、UI等で「法定」と断定して表示しない。 |
| **8.75h 基準（STATUTORY_DAILY_LIMIT_HOURS）** | 休憩（第34条）を法定労働時間（第32条：8時間）に足し込む法的根拠はない。 | 廃止（FD-01）し、実働8時間基準へ移行する。 |

## 1. 実装フェーズの全体像

1. **フェーズ 1：法的引用・コメントの全件訂正（挙動不変）**
   - コードおよびドキュメント内の条文番号（第9条→第32条/第34条、労安法68条②など）を訂正。
   - レグレッション防止の静的ガードテストを追加。
2. **フェーズ 2：1日労働時間判定の適正化（FD-01）**
   - 8.75h 基準（`STATUTORY_DAILY_LIMIT_HOURS`）を廃止。
   - 実働 8 時間超過に対する判定を `OVERTIME_NOT_ALLOWED`（残業不可時のBLOCKER）と `OVERTIME_REQUIRES_36AGREEMENT`（36協定・割増賃金確認のWARNING）に分離。
3. **フェーズ 3：給与計算・統計出力のラベルおよび表現の適正化**
   - `exporter.py` の `PAYROLL_DF_COLUMNS` に「割増未反映（概算）」の注記や列の明確化を行い、法的誤認を防ぐ。
4. **フェーズ 4：回帰防止テストの網羅と結合検証**
   - 終了コード不変の確認、静的ガードのCI組み込み。

## 2. 各フェーズの詳細実装ステップ

### フェーズ 1：法的引用・コメントの訂正（1 ステップ = 1 コミット）

#### Step 1-1: `domain.py` および `gap_analysis.py` の法令参照の訂正
- **変更ファイル**: `src/shiftai/domain.py`, `src/shiftai/gap_analysis.py`
- **内容**:
  - `domain.py:320` の「労働基準法第9条に対応」を「労働安全衛生法第68条第2項に対応」へ訂正。
  - 休憩に関する言及を「労働基準法第34条」へ訂正。
- **テスト**: 既存テストが全てパスすることを確認。

#### Step 1-2: `local_rules.py` の法的根拠コメントの訂正
- **変更ファイル**: `src/shiftai/local_rules.py`
- **内容**:
  - `_LEGAL_BASE` 及び各ノートの `legal_reference` から「第32条の3（休息日）」を削除し、「第35条（休日）」「第39条（年次有給休暇）」へ整理。
  - 「第9条（労働時間・休息）」を「第32条（労働時間）・第34条（休憩）」へ訂正。
- **テスト**: `tests/test_config.py` および `tests/test_local_rules.py` がパスすること。

#### Step 1-3: 静的ガードテスト（回帰防止）の追加
- **変更ファイル**: `tests/test_docs_regulation.py`（または新規 `tests/test_legal_citations.py`）
- **内容**:
  - コードベース内を走査し、廃止すべき誤った条文引用（例：`労働基準法第9条.*休息` や `第32条の3.*休息日`）が再発していないかを検証するユニットテスト `test_no_obsolete_legal_citations` を実装。
- **受入基準**: 誤った引用が検知された場合にテストが失敗すること。

### フェーズ 2：1日労働時間の判定適正化（FD-01 実装）

#### Step 2-1: 8.75h 基準定数の廃止と新違反コードの導入
- **変更ファイル**: `src/shiftai/config.py`, `src/shiftai/gap_analysis.py`
- **内容**:
  - `config.py` の `STATUTORY_DAILY_LIMIT_HOURS` に `DeprecationWarning` の注記を追加（後方互換のため値は残す）。
  - `gap_analysis.py` の `check_violations` において、実働 8 時間（480分）を超える勤務の判定を以下に置換：
    - `overtime_allowed=False` の場合：`OVERTIME_NOT_ALLOWED`（Severity: **BLOCKER**）
    - `overtime_allowed=True` の場合：`OVERTIME_REQUIRES_36AGREEMENT`（Severity: **WARNING**）
- **テスト**:
  - `FD-01-R1`: 残業不可の職員が8.5時間勤務した際に `OVERTIME_NOT_ALLOWED`（BLOCKER）が検出されること。
  - `FD-01-R2`: 残業可の職員が9時間勤務した際に `OVERTIME_REQUIRES_36AGREEMENT`（WARNING）が検出されること。
  - `FD-01-R3`: 8.0時間ちょうどではいずれの違反も出ないこと。

## 3. リグレッション防止策（テスト計画）

1. **静的コード解析（Ruff）**:
   - コミット前に必ず `ruff check .` を実行し、構文・未使用インポート・スタイル違反を排除。
2. **静的法規引用ガード（`test_legal_citations.py`）**:
   - ソースコードおよびドキュメント内の正規表現マッチングにより、廃止された誤った条文番号（例：「第9条（休息）」、「第32条の3（休息日）」など）の混入を自動検知してブロック。
3. **境界値ユニットテスト**:
   - 労働時間（480分・481分）、休憩閾値（360分・361分、480分・481分）の境界における判定の正確性を保証するテストケースを常時実行。
4. **終了コードの不変性検証**:
   - サンプルデータに対するソルバ実行および監査実行において、意図しないBLOCKERの発生や終了コードの変動がないことを結合テスト（`test_e2e.py` 等）で担保。
