## 1. フェーズ 1: 未定義名の解消（P1・P5）

### 1.1 方針決定

`model_builder.py` は「MILP モデル構築部品」として `solver.py` から切り出されたが、
**切り出しが中途半端**な状態である。2 つの選択肢がある。

* **案 A（推奨）**: `model_builder.py` を完走させる。`solver.py` から構築系コードを削除し、
  `solver.py` は「実行・検証・後処理」だけにする。
* **案 B**: `model_builder.py` / `decoder.py` を `solver.py` に再統合して削除する。

本計画では **案 A** を採用する（既に `_build_problem` など移行済みコードが多く、
戻すより進めた方が総工数が少ない）。ただし案 B への切替判断基準は
「1.3 の移行で 1 週間以上かかりそうなら案 B に戻る」とする。

## 2. フェーズ 2: バージョン解決の修正（P2）

### 2.1 問題の構造

`shiftai/__init__.py::_resolve_version()` は:

1. `importlib.metadata.version("shiftai")` → **古い 0.5.0** を返す
2. pyproject.toml フォールバック → 読まれない

開発環境で `pip install -e .` を更新していないと常に発生する。
また `--version` 出力（`test_portability.py::test_version表示`）も subproc で
同様に古いメタデータを使う。

### 2.2 修正方針

「dist メタデータが唯一の真実」という設計思想自体は正しいので**維持**しつつ、
開発環境での取りこぼしを防ぐ。

| タスク | 内容 |
|--------|------|
| T2-1 | `_resolve_version()` に「ソースツリー判定」を追加: `shiftai/__init__.py` の親ディレクトリに `pyproject.toml` が存在し、かつ `pip` の直接 URL editable インストール（`direct_url.json` の `url` がローカルパス）である場合、pyproject の値を優先する。シンプル化するなら「dist 側 `direct_url.json` が editable/ローカルなら pyproject を優先」でもよい |
| T2-2 | CI と開発手順の明記: `docs/05_開発ガイド.md` に「バージョンを上げたら `pip install -e .` を再実行」と追記。`Makefile` に `make sync-version`（`pip install -e . --no-deps -q`）ターゲットを追加 |
| T2-3 | `pyproject.toml` のバージョンを单一代替として `src/shiftai/__init__.py` に動的取得させる（`[project] dynamic = ["version"]` + `[tool.setuptools.dynamic] version = {attr = "shiftai.__version__"}`）方式への切替は**慎重に**。既存テストが pyproject 直読み前提のため、本タスクは T2-1 で緑になった後、別 PR で検討する |

### 2.3 完了条件（フェーズ 2）

```bash
pip install -e . --no-deps -q && python -m pytest tests/test_portability.py -q
# → 25 passed
```

## 7. リグレッション防止策（本計画の修正で壊させない）

1. **golden master**: フェーズ 5 の各 PR で `test_golden_master.py` を必ず実行。
   スナップショット差分が出た場合は意図的挙動変更の証明（テスト期待値更新の根拠）を PR 説明に書く。
2. **`test_static_guards.py`**: import 構造のガードテストがあるため、
   再エクスポート漏れはこのテストが検知する。新規分割ファイル作成時に
   ここへ制約を追加する。
3. **親ディレクトリ実行テスト**: フェーズ 3 の T3-4 で「`cd ..` からの実行」を
   `REGRESSION_TEST_PLAN.md` の必須手順に加え、相対パスバグの再発を防ぐ。
4. **Ruff を CI で強制**: `.github/workflows/tests.yml` に
   `ruff check src tests` を追加（現在 lint は任意実行の可能性が高い）。
   これで F821 クラスの「未定義名がマージされる」事故を機械的に防ぐ。
5. **UP042 無効化の維持**: `pyproject.toml` の意図（`str, Enum` 保持）を
   変えない。理由は既存コメントに記録済み。
