## Phase 2: テストの実行ディレクトリ依存の解消

### 2.1 方針

テスト内の相対パス参照は `Path(__file__)` ベースに置換する。
`os.chdir` による回避は並列実行（pytest-xdist）と相性が悪いため使わない。

### 2.2 該当パターンの洗い出し

```bash
grep -rn "src\\\\shiftai\|src/shiftai\|docs\\\\" nushift/tests
```

想定される箇所（失敗テストより）:

| テスト | 参照先 |
|---|---|
| `test_static_guards.py` 系 | `src/shiftai/local_rules.py` |
| `test_docs_regulation.py` | `docs/03_配置基準と自治体ルール.md` |
| `test_docs_sync.py` 系 | `docs/05_開発ガイド.md` など |

### 2.3 実装

共通ヘルパーを `tests/conftest.py` に追加:

```python
from pathlib import Path

PROJECT_ROOT = Path(__file__).resolve().parent.parent
SRC_DIR = PROJECT_ROOT / "src" / "shiftai"
DOCS_DIR = PROJECT_ROOT / "docs"


def project_path(*parts: str) -> Path:
    return PROJECT_ROOT.joinpath(*parts)
```

各テストで `"src/shiftai/local_rules.py"` → `project_path("src", "shiftai", "local_rules.py")` に置換。
